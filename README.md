# 台山市鹏权中学 · 校园三维模型

用 Three.js 在浏览器里还原的台山市鹏权中学（广东省江门市台山市台城街道环市西路）校园，可以从俯视、鸟瞰和第一人称三种视角浏览。

所有建筑、地面和树木都由代码生成，不含任何卫星图或照片素材。

## 打开方式

- 直接双击 `index.html`。
- 如果打不开，运行 `start.bat`（需要已安装 Python），它会启动本地服务并自动打开页面。

three.js 已放在 `vendor/` 里，不联网也能运行；本地文件缺失时会自动改用 CDN。

## 操作

| 视角 | 操作 |
|---|---|
| ① 俯视 | 左键拖动平移，滚轮缩放，右键拖动或 Q / E 旋转 |
| ② 鸟瞰 | 左键拖动环绕，右键拖动（或 Shift + 拖动）平移，滚轮缩放 |
| ③ 第一人称 | 点击画面锁定鼠标转向（Esc 释放），WASD 移动，Shift 奔跑，空格跳跃，F 切换飞行（空格升、C 降） |

- 数字键 1 / 2 / 3 切换视角，L 开关建筑标注，M 开关小地图。
- 右上角可以调时间（改变日照和阴影）、快速定位到校门、广场、田径场等位置。
- 点击小地图可以直接跳转。

## 模型包含的内容

- 教学区：第一教学大楼（门厅前有通到二层平台的大楼梯）、第二教学楼、科艺楼
- 生活区：学生宿舍、综合楼、新生活楼（饭堂和宿舍）
- 运动区：400 米田径场和主席台、篮球场、排球场、游泳池
- 校门、校名墙、门卫室、林荫主道、中心广场、花园和凉亭
- 周边：环市西路、教师宿舍（桃李园）、周围街区和南侧山林

## 依据与准确程度

- **平面布局**：按高德、百度卫星图逐块量测，建筑位置和尺寸是实测值（教学区除外，见下一条）。校园朝向与正北偏约 45°；环市西路与校园实际有约 3° 的夹角，模型里简化成了平行。
- **有意与实际不同的部分（教学区）**：
  - 没有建扩建工程的新教学楼。
  - 第一教学大楼和它后面相连的第二教学楼、科艺楼整体向前（朝花园和主干道方向）平移了 30 米，第一教学大楼占到了新教学楼原来的位置。
  - 第一教学大楼门厅二层平台前加了一座直通地面的大楼梯，第一人称可以走上去。
- **有照片依据的外观**：校名墙、校门立柱、7 层学生宿舍、第一教学大楼的玻璃门厅和楼顶标语、田径场主席台、中心广场的红色石带。
- **新生活楼**：位置来自较新的卫星图，层数来自扩建工程公开文件（6 层）；没有找到实景照片，外观按常见新校舍样式设计。
- **推断的部分**：
  - “科艺楼”“第二教学楼”两个楼名是推断的，可能与实际不符。
  - 其余教学楼的层数按卫星图阴影估算。
  - 西侧新建运动场地的球场划线按文件描述绘制。
  - 宿舍楼壁柱文字（用了校训）、主席台横额（用了校名）、第一教学大楼前的圆形花坛和电子屏是代填的。

## 目录结构

```
index.html              页面与界面
js/core.js              工具库：引擎加载、程序化贴图、几何批处理
js/campus.js            校园数据与建模（坐标、建筑、场地、树木）
js/app.js               渲染、三种视角控制、小地图与标注
vendor/three.global.js  three.js r170（MIT 许可）
start.bat               本地服务启动脚本
```

坐标约定见 `js/core.js` 开头的注释：X 轴沿环市西路指向东南，Y 轴指向东北（校门一侧），单位为米。
